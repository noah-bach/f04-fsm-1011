# F04 - FSM phát hiện chuỗi 1011

Môn: EEE703128 - Nhập môn Thiết kế Vi mạch Tích hợp.

## Mục tiêu
Thiết kế hai FSM cùng đọc một luồng bit và phát hiện mẫu 1011, có chồng lấn.
Kiểm chứng bằng mô phỏng, chạy flow của lớp và giải thích kết quả bằng bằng chứng.
